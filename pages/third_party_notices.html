Components and feature scope

Vimium v2.4.2 (MIT)
Powers keyboard navigation and input modes (normal, insert, visual), Link Hints, keyboard scrolling, in-page find (/), Marks, Vomnibar search with bookmark/history/tab completion, the keyboard HUD, URL exclusion rules, and the legacy options, help dialog, and command listing pages.
yaml 2.9.1 (ISC)
Powers local YAML parsing and serialization in the Properties / YAML converter tool.
shoulda.js (MIT, test only)
Provides the unit-test framework during development and build verification; it is not part of the extension's runtime features.
Browser Toolbox modules (GPL-3.0-or-later)
Independently implemented features: mouse gestures (trail HUD, cancel target, right-click guard, cross-frame bridge), super drag, wheel gestures, rocker gestures, custom pointer cursor, unified command dispatcher and command center, tab list popup, automatic JSON page formatter, 8 offline developer/text/generator/table tools, per-site module rules, configuration schema migration and import recovery, localization, and the unified settings UI.
