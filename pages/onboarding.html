Browser Toolbox

A local browser workflow toolbox for Chromium browsers, with keyboard navigation and independent mouse input modules.

  • When menu suppression is enabled, right-button gestures block conflicting native menus from button-down; disabling it keeps the native menu but may conflict with gestures.
  • Super drag leaves file upload, editors, password fields, and custom draggable widgets alone.
  • Every action is routed through a validated command invocation.
  • No telemetry, accounts, advertising, or paid features.
