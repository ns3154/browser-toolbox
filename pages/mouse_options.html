Search engines

Bind search engines to short keywords and trigger them directly from the quick launcher (Vomnibar).

  1. Step 1 · Configure & save Edit keyword rules below

    One entry per line as "keyword: search_url [name]" (e.g. g: https://google.com/search?q=%s Google), then click Save settings.

  2. Step 2 · Open on any page Press o (current tab) or O (new tab)

    Opens the quick launcher (requires Keyboard navigation enabled, or open via gesture/command center).

  3. Step 3 · Search with keyword Default example: type g query and press Enter

    Type g, a space, and your search terms. If you changed the rules, use your configured keyword instead.

Line syntax
Format: keyword: URL [display name] (e.g. g: https://google.com/search?q=%s Google). %s is replaced with the URL-encoded query, %S keeps the raw query, or it is appended if omitted.
Comments & saving
Lines starting with # or " are treated as comments and ignored; click Save settings to apply changes.

Searches are sent only when you explicitly invoke a search command.

  2. Step 2 · Browse Try shortcuts on a web page

    Use j / k to scroll, f to open link hints, and ? to see all shortcuts.

    Rules & data

    Backup & Restore

    Exports contain settings only. Page content, history, bookmarks, temporary gestures, and remote assets are never exported.

    You can also import a Vimium JSON backup. Recognized fields are copied to the compatible Vimium settings and Browser Toolbox settings; unknown fields are reported and ignored.

    Local backups before import

    Before each import, saved settings and any available local pointer image are kept on this device. You can add a backup image to the draft or export it separately. Settings exports do not include images. Previous pointer images use local storage; safe cleanup is not yet available.
