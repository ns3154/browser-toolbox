Privacy

No telemetry, accounts, advertising, or paid features.

Data handling

Browser Toolbox does not send URLs, history, bookmarks, page content, selected text, search terms, keystrokes, mouse paths, pointer images, configuration, device identifiers, installation identifiers, or crash reports to a project server or third-party analytics service.

Submitting a search sends the query to the selected search engine. When a custom search rule supports suggestions, the extension may send search terms to that suggestion service over HTTPS before submission.

Local storage

The browser stores settings and can sync them across devices through its built-in sync service. Custom pointer images stay on this device.
