Security

Local tools process input in the browser. The extension does not load remote code or let web pages invoke privileged actions directly.

Imported settings are parsed, validated, previewed, and confirmed before they are written. Import files are never executed as HTML or script.

Submitting a search sends the query to the selected search engine. When a custom search rule supports suggestions, the extension may send search terms to that suggestion service over HTTPS before submission.

Do not include credentials, cookies, tokens, personal data, or complete browsing data in a public issue.
