# 浏览器工具箱

[English](README.md) | **简体中文**

用键盘和鼠标浏览网页、搜索内容、管理标签页和窗口。

## 安装

当前可从 GitHub 下载使用：

1. 下载仓库并解压。
2. 在 Chrome 或 Chromium 地址栏打开 `chrome://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目目录。
5. 点击浏览器工具栏中的扩展图标，选择“打开设置”。

扩展无法在 `chrome://`、应用商店等浏览器管理页面运行，请在普通网页中使用。

## 快速开始

- 在网页中按 `?`，打开帮助并查看完整快捷键。
- 点击扩展图标，可以查看当前网站的功能状态，并临时开关键盘、鼠标手势、超级拖拽和滚轮/摇杆。
- 在“打开设置”中修改功能和操作绑定，修改后点击“保存”。

## 常用键盘操作

| 按键                  | 操作                                                  |
| --------------------- | ----------------------------------------------------- |
| `?`                   | 打开帮助                                              |
| `h` / `j` / `k` / `l` | 向左 / 下 / 上 / 右滚动                               |
| `gg` / `G`            | 滚动到页面顶部 / 底部                                 |
| `f` / `F`             | 显示提示并在当前标签页 / 新标签页打开链接             |
| `o` / `O`             | 在当前标签页 / 新标签页搜索或打开网址、书签和历史记录 |
| `T`                   | 搜索已打开的标签页                                    |
| `H` / `L`             | 后退 / 前进                                           |
| `J` / `K`             | 切换到上一个 / 下一个标签页                           |
| `t`                   | 新建标签页                                            |
| `x` / `X`             | 关闭 / 恢复标签页                                     |
| `/`，`n` / `N`        | 查找文字，跳到下一个 / 上一个匹配结果                 |
| `yy`                  | 复制当前网址                                          |
| `Esc`                 | 取消当前操作或退出输入模式                            |

帮助中的按键会随自定义设置变化，以上是常用默认按键。

## 鼠标手势

默认使用右键和八方向识别：按住右键，按方向移动，松开执行动作。设置页使用 `↑`、`↓`、`←`、`→` 和
`↖`、`↗`、`↙`、`↘` 表示八个方向；多段手势用 `·` 分隔。

| 轨迹                      | 默认操作                    |
| ------------------------- | --------------------------- |
| `←`                       | 后退                        |
| `→`                       | 前进                        |
| `↑` / `↓`                 | 向上 / 向下翻一整页         |
| `↓ · →`                   | 关闭当前标签页              |
| `← · ↑`                   | 恢复最近关闭的标签页        |
| `→ · ↓` / `→ · ↑`         | 到页面底部 / 顶部           |
| `↑ · ↓`                   | 刷新页面                    |
| `↑ · ↓ · ↑`               | 强制刷新页面                |
| `↑ · ←` / `↑ · →`         | 切换到上一个 / 下一个标签页 |
| `↓ · → · ↑` / `↑ · → · ↓` | 新建窗口 / 关闭当前窗口     |
| `→ · ↓ · ← · ↑`           | 打开浏览器工具箱设置        |

启用右键菜单接管时，按住并移动执行手势；不移动时，在同一位置快速点击两次右键可打开浏览器原生菜单。
触发按键、方向模式、轨迹显示和动作绑定都可以在设置中修改。

## 超级拖拽

按住左键拖拽链接、选中文字或图片，按方向移动后松开即可执行动作。默认操作如下：

| 对象     | 方向      | 默认操作                          |
| -------- | --------- | --------------------------------- |
| 链接     | `→` / `←` | 当前标签页打开 / 后台新标签页打开 |
| 选中文字 | `→` / `←` | 前台搜索 / 后台搜索               |
| 选中文字 | `↓`       | 复制文字                          |
| 图片     | `→` / `←` | 当前标签页打开 / 后台新标签页打开 |
| 图片     | `↓`       | 复制图片网址                      |
| 图片     | `↓ · →`   | 下载图片                          |

按住 `Alt` 拖拽可保留浏览器原生拖拽行为。文件上传、编辑器、密码框等场景不会被超级拖拽接管。

## 滚轮与摇杆

- 按住右键滚轮：向上到页面顶部，向下到底部。
- 按住左键滚轮：向上切换到上一个标签页，向下切换到下一个标签页。
- 按住右键点击左键：后退。
- 按住左键点击右键：前进。

未绑定的组合仍保持普通点击或滚轮行为。若多个鼠标功能使用同一个按键，鼠标手势优先。

## 设置

点击扩展图标中的“打开设置”，可以进行以下操作：

- 在“导航与键盘”中开关键盘导航、修改快捷键和搜索引擎。
- 在“鼠标与拖拽”中开关鼠标功能，新增或修改手势、超级拖拽、滚轮和摇杆动作。
- 在“外观与行为”中显示或隐藏轨迹、命令提示，以及选择本地 PNG 指针。
- 在“站点规则”中按网址启用工具箱，或只停用某个网站的鼠标模块。
- 在“备份与恢复”中导出设置，或导入已有设置文件；导入前可以先预览变更。

修改设置后点击“保存”即可生效。
