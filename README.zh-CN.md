# 浏览器工具箱

[English](README.md) | **简体中文**

浏览器工具箱基于 Vimium v2.4.2 的键盘导航能力，增加鼠标手势、超级拖拽、滚轮与摇杆、站点规则、浏览器启动与新标签页动作，以及一组完全在本地运行的实用工具。

当前 `manifest.json` 版本为 `0.1.2`。它是源码版本号，不代表 Chrome Web Store 审核或发布状态。

## 功能总览

| 模块 | 能力 |
| ---- | ---- |
| 键盘导航 | 页面滚动、链接提示、搜索/书签/历史/标签页、查找、标记、标签页与窗口管理、缩放、刷新和 Vimium 兼容映射 |
| 鼠标输入 | 四方向鼠标手势、多段轨迹、超级拖拽、滚轮切换、摇杆后退/前进和可配置命令 |
| 浏览器工作流 | 命令中心、动作弹窗、当前站点管理、全部网站会话暂停/恢复、浏览器启动/新标签页动作、工具栏快捷入口 |
| 本地工具 | JSON、Properties ↔ YAML、文本对比、编码转换、时间、ID、密码和 CSV/TSV 工具 |
| 站点控制 | Glob/正则规则、匹配优先级、站点配置档、按站点停用模块和规则解释/测试 |
| 配置管理 | 五种语言、导入预览、导出备份、Vimium 配置兼容、配置迁移和浏览器同步边界说明 |
| 隐私 | 无账户、无广告、无订阅、无遥测、无远程代码；工具和配置默认在本地处理 |

## 安装

当前支持 Chrome 或 Chromium 117 及以上版本。开发版安装步骤如下：

1. 从 [GitHub 仓库](https://github.com/ns3154/browser-toolbox) 下载源码并解压。
2. 在地址栏打开 `chrome://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目目录。
5. 点击浏览器工具栏中的扩展图标，选择“打开设置”。

键盘和鼠标输入模块不能运行在 `chrome://`、Chrome Web Store 等浏览器管理页面上；在这些页面仍可以从扩展弹窗打开“全部工具”和设置。若要在 `file://` 页面使用内容功能，还需要在扩展详情中允许访问文件网址。

## 快速开始

1. 打开普通网页，按 `?` 查看帮助和当前可用的键盘操作。
2. 按 `:` 打开命令中心，搜索命令、工具或设置。
3. 点击扩展图标，在“快捷工具”中打开 JSON 格式化或文本对比。
4. 在“打开设置”中启用需要的模块、修改绑定，最后点击“保存设置”。
5. 如果网页控件与扩展冲突，在弹窗中点击“暂停所有网站”；处理完后点击“恢复本次会话”。只想长期调整一个网站时，使用“管理此网站”创建站点规则。

在“常规 → 语言”中可以选择简体中文、繁体中文、English、日本語、Español 或“跟随浏览器”。

## 键盘导航

浏览器工具箱保留 Vimium 的键盘工作流，并通过命令注册表提供搜索和自定义入口：

- 使用 `h` / `j` / `k` / `l`、`gg` / `G`、`d` / `u` 和方向命令滚动页面。
- 使用 `f` / `F` 显示链接提示，在当前标签页、前台新标签页或其他目标中打开链接；也支持复制、下载等链接操作。
- 使用 `o` / `O` 打开 Vomnibar，搜索网址、书签、历史和已打开标签页；可配置搜索引擎。
- 使用 `T` 搜索已打开的标签页，使用 `H` / `L` 后退或前进，使用 `J` / `K` 切换标签页。
- 使用 `t`、`x` / `X`、`r` / `R` 管理新建、关闭、恢复和刷新；使用 `zi` / `zo` / `z0` 调整缩放。
- 使用 `/`、`n` / `N` 查找文字，使用 `m` / `'` 创建和跳转页面标记，使用 `yy` 复制当前网址。
- 支持标签页固定、静音、移动、复制、按左右侧关闭、窗口管理、查看网页源代码和全屏等命令。

常用默认按键：

| 按键 | 操作 |
| ---- | ---- |
| `?` | 打开帮助 |
| `:` | 打开命令中心 |
| `h` / `j` / `k` / `l` | 向左 / 下 / 上 / 右滚动 |
| `gg` / `G` | 滚动到页面顶部 / 底部 |
| `f` / `F` | 当前标签页 / 新标签页打开链接 |
| `o` / `O` | 当前标签页 / 新标签页搜索或打开网址、书签和历史 |
| `T` | 搜索已打开的标签页 |
| `H` / `L` | 后退 / 前进 |
| `J` / `K` | 切换到上一个 / 下一个标签页 |
| `t` | 新建标签页 |
| `x` / `X` | 关闭 / 恢复标签页 |
| `/`，`n` / `N` | 查找文字，跳到下一个 / 上一个匹配结果 |
| `yy` | 复制当前网址 |
| `Esc` | 取消当前操作或退出输入模式 |

帮助中的按键会随自定义设置变化。可以在“键盘”设置中编辑 Vimium 兼容的键位映射；键位映射和搜索引擎继续使用 Vimium 原有的浏览器同步。

## 鼠标手势

### 鼠标轨迹

默认使用右键和四方向识别：按住右键，向上、下、左或右移动，松开执行动作；多段手势用 `·` 分隔。触发按键、激活距离、采样距离、转向迟滞、最大分段数、最长时长、轨迹和命令提示都可以在设置中调整。

| 轨迹 | 默认操作 |
| ---- | ---- |
| `←` | 后退 |
| `→` | 前进 |
| `↑` / `↓` | 向上 / 向下翻一整页 |
| `↓ · →` | 关闭当前标签页 |
| `← · ↑` | 恢复最近关闭的标签页 |
| `→ · ↓` / `→ · ↑` | 到页面底部 / 顶部 |
| `↑ · ↓` / `↑ · ↓ · ↑` | 刷新 / 强制刷新页面 |
| `↑ · ←` / `↑ · →` | 切换到上一个 / 下一个标签页 |
| `↓ · → · ↑` / `↑ · → · ↓` | 新建窗口 / 关闭当前窗口 |
| `→ · ↓ · ← · ↑` | 打开浏览器工具箱设置 |

启用右键菜单接管时，按住并移动执行手势；不移动时，在同一位置快速点击两次右键可打开浏览器原生菜单。未触发手势时，普通点击行为仍会保留。

### 超级拖拽

按住左键拖拽链接、选中文字或图片，按方向移动后松开即可执行动作：

| 对象 | 方向 | 默认操作 |
| ---- | ---- | ---- |
| 链接 | `→` / `←` | 当前标签页打开 / 后台新标签页打开 |
| 选中文字 | `→` / `←` | 前台搜索 / 后台搜索 |
| 选中文字 | `↓` | 复制文字 |
| 图片 | `→` / `←` | 当前标签页打开 / 后台新标签页打开 |
| 图片 | `↓` | 复制图片网址 |
| 图片 | `↓ · →` | 下载图片 |

按住 `Alt` 拖拽可保留浏览器原生拖拽行为。文件上传、编辑器、密码框等受保护控件不会被超级拖拽接管。

### 滚轮与摇杆

- 按住右键滚轮：向上到页面顶部，向下到底部。
- 按住左键滚轮：向上切换到上一个标签页，向下切换到下一个标签页。
- 按住右键点击左键：后退。
- 按住左键点击右键：前进。

滚轮阈值、冷却时间和连续切换标签页可以配置。未绑定的组合仍保持普通点击或滚轮行为；多个鼠标功能使用同一按键时，鼠标手势优先。

## 命令中心、弹窗与会话控制

- **命令中心**：按 `:` 或从扩展弹窗打开，搜索浏览器命令、本地工具和设置；按 `Enter` 执行，按 `Esc` 关闭。
- **动作弹窗**：显示当前站点状态、四个浏览增强模块的当前会话开关、快捷工具、命令中心、全部工具、帮助和设置入口。
- **当前会话暂停**：可以暂停全部网站的键盘、鼠标、超级拖拽和滚轮增强；恢复后重新采用已保存设置和站点规则。临时开关不会覆盖持久配置。
- **管理此网站**：从普通网页的扩展弹窗进入设置时，会定位同源站点规则，或带入当前网址创建规则草稿；检查并保存后才生效。
- **受限页面**：浏览器禁止内容脚本运行时，弹窗会说明原因，但仍保留工具、设置和帮助入口。

## 本地工具

点击扩展图标中的“全部工具”，或从命令中心搜索工具：

| 工具 | 能力 |
| ---- | ---- |
| JSON 格式化 | 格式化、压缩、校验、排序、展开转义 JSON；支持缩进、修复选项、复制和下载 |
| Properties ↔ YAML | 在 Properties 和 YAML 配置文本之间互转；对路径、类型、空值和不支持语法给出明确错误 |
| 文本对比 | 对比两段本地文本并复制结果 |
| 编码转换 | Unicode、Base64、URL/URI、JSON/XML、二进制、八进制、十进制、ASCII、Data URL 等编码/解码；包含兼容性摘要算法入口 |
| 时间转换 | ISO 时间、Unix 秒/毫秒、时区显示、Windows FILETIME 和世界时钟 |
| ID 生成 | UUID v4、ULID 风格、Snowflake 风格和 NanoID 风格 ID；支持一次生成 1、5 或 10 个 |
| 密码生成 | 生成 12、20、32 或 64 位随机密码，可控制是否包含符号 |
| CSV / TSV 转换 | 转换为 Markdown、CSV、TSV、JSON、XML、MySQL `INSERT` 或 PHP 数组 |

工具输入都在浏览器本地处理，支持复制和适用时下载结果。工具目录会显示分类、关键词和入口；在“工具总览”中可以分别配置动作弹窗和原生右键菜单，符合入口条件的工具可以任意多选，不再有产品内部的三项或六项上限。右键菜单只为支持该入口的工具提供选项，ID 和密码生成器等无文本输入工具保留在动作弹窗和命令中心中。

### 文档自动格式化

可在“JSON 格式化”设置中启用网页文档自动格式化，支持 JSON、XML、CSS、JavaScript 和 Java。可以分别开关格式类型、设置自动处理的最大字节数，以及 JSON 的键排序和默认折叠深度；匹配的文档内容只在本地读取，不上传页面数据。

## 浏览器启动与新标签页网站

在“常规 → 浏览器启动”中填写一个 `http://` 或 `https://` 地址。两个开关相互独立：

- **Chrome 启动时打开网站**：Chrome 用户配置文件启动时打开配置的网站。
- **新标签页也打开此网站**：普通窗口中新建标签页时跳转到同一个网站。

- 启动动作每次 Chrome 用户配置文件启动时最多打开一次。
- 启动动作优先在聚焦的普通窗口中新建活动标签页；没有聚焦窗口时使用第一个普通窗口；没有普通窗口时创建普通窗口。Chrome 恢复的已有标签页会保留。
- 新标签页跳转只作用于普通窗口；无痕窗口仍使用浏览器原生新标签页。
- 关闭新标签页开关后，浏览器恢复原生新标签页行为，已填写的网址不会被清空。
- 不接受 `file:`、`javascript:`、`data:`、`chrome:` 等非 HTTP(S) 协议；只处理浏览器原生新标签页事件，不会改写普通网页。

新标签页功能使用运行时跳转，因此关闭开关后仍保留浏览器原生新标签页；[newtab-redirect](https://github.com/jimschubert/newtab-redirect) 可作为浏览器新标签页行为的参考。

### 站点规则与配置档

站点规则支持 Glob 通配式和显式正则表达式。规则会根据匹配度、优先级和配置顺序计算最终状态，并可测试网址、查看匹配解释、停用工具箱或只停用鼠标/超级拖拽/滚轮等模块。内置配置档包括：

- **均衡**：普通浏览的标准阈值。
- **编辑器安全**：在编辑器和设计工具中减少误触手势。
- **阅读**：长时间阅读时减少输入反馈干扰。
- **自定义配置档**：只覆盖需要改变的字段，其余继承全局设置。

### 导入、导出与同步

- 导出文件只包含设置，不包含页面内容、历史、书签、临时会话开关或远程资源。
- 导入设置前可以预览变更；支持浏览器工具箱配置和兼容的 Vimium JSON 备份，未知字段会列出并忽略无法兼容的部分。
- 配置 schema 会在读取时逐级迁移，旧配置会补齐新功能的默认值。
- “同步工具箱配置”只控制浏览器工具箱的鼠标行为、工具和站点规则。键位映射和搜索引擎继续使用 Vimium 原有同步。
- Chrome 同步存在单项和总容量限制；超限时可以精简配置，或关闭工具箱同步后仅保存在本地。
