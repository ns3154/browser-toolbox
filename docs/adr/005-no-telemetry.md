# ADR-005：零遥测与无后台网络

- 状态：已接受
- 日期：2026-08-23

## 决策

扩展不收集、不发送、不持久化遥测数据，不建立账户、设备
ID、远程配置、崩溃上报或项目服务器。允许的网络行为仅限用户主动打开网页、主动选择搜索引擎查询、主动打开项目资料，以及浏览器自身的扩展更新。

扩展运行时禁止远程 JavaScript、eval、new Function、CDN
代码和动态下载后执行的代码。未来任何例外必须先公开 ADR、说明必要性、替代方案和隐私影响。

## 验证要求

每阶段记录真实网络/权限检查结果；未完成审计不能宣称零网络调用已经通过。当前 checkout 已提供权限和新增
模块网络审计脚本，并在发布门禁中运行；审计结果只证明当前源码范围，不替代后续代码变更后的重新审计。
