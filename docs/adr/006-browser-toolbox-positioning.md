# ADR-006：浏览器工具箱产品定位与命名边界

- 状态：已接受；技术命名部分由 ADR-007 取代
- 日期：2026-08-24

## 决策

本项目正式采用“浏览器工具箱”（Browser Toolbox）作为对外产品名，产品定位是永久免费、开源、本地优先、无遥测的浏览器工作流工具箱。
它以 Vimium 的键盘导航和命令基础为一部分，统一承载网页导航、页面对象操作、搜索、标签页/窗口控制、设置和站点规则；鼠标轨迹、超级拖拽、滚轮和摇杆是其中的输入模块。

图标归属、商标可用性和法律结论必须另行检索和记录；产品名已确定不代表已经完成商标确认。

## 技术兼容边界

本 ADR 只记录产品定位决策。技术标识迁移、旧配置读取和回滚边界由 ADR-007 规定；产品定位不授权复制竞品实现，也不改变扩展 ID。

## 竞品边界

- Vimium 是上游代码、许可证和键盘行为基线，不是本项目对外品牌。
- CrxMouse 仅可作为鼠标输入模块中部分公开行为的参考，不是本项目整体功能清单、产品定位、代码、资产、文案或界面来源。
- 任何新增模块都必须先说明其与浏览器工作流的关系、权限影响、离线边界和测试证据，不能因为竞品存在就自动纳入。

## 影响

本轮只同步产品文案、设计文档、治理文档和本地化 fallback；不新增功能、权限、依赖、网络行为，也不提前恢复人工验收。
