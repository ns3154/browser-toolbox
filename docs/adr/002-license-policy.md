# ADR-002：许可证与永久免费政策

- 状态：已接受
- 日期：2026-08-23

## 决策

项目整体发行物使用 GPL-3.0-or-later，并保留 Vimium 的 MIT
许可证、版权声明和第三方通知。全新项目代码使用 GPL-3.0-or-later；直接来源或修改自 Vimium
的文件继续遵守 MIT 许可义务。

官方仓库、官方安装包和官方商店版本永久免费，不提供广告、账户、订阅、付费功能或商业版。

## 法律边界

GPL
允许符合条件的第三方收费再分发，因此本项目不把“禁止第三方收费”写成许可证限制。官方身份、名称和商标规则用于防止冒充官方收费版本。

## 结果

本 ADR 不授权新增功能，也不改变 Phase 0 以外的代码。
