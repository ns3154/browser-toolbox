# 浏览器工具箱人工验收操作清单

本清单服务于设计文档 §18.4 和 `docs/release-checklist.md`。它是执行说明，不是验收结果。
只有在对应浏览器和操作系统中实际完成操作、记录版本与结果后，才可以把矩阵中的“手工测试”改为
`PASS` 或把功能状态改为 `DONE`。自动化 E2E、隔离 profile 和历史记录不能代替人工结果。

## 0. 证据规则

- 每次使用当前 checkout 构建的临时 profile；记录日期、操作系统、浏览器精确版本、扩展版本、扩展 ID
  和当前 Git SHA。
- 不使用日常浏览器 profile，不登录 Gmail、Google Docs、Notion 或其他站点，不保存密码、Cookie、Token
  或个人资料。需要登录态才能验证的场景只记录“未验证”，不要用登录页冒充业务流程。
- 每个用例都记录“通过、失败、未执行”三态、复现步骤和截图/日志位置。自动化结果只能作为补充证据。
- 只接受与当前测试明确相关的浏览器提示。若出现“允许访问文件网址”之类提示，先核对提示对象确实是
  当前扩展和临时 profile；摄像头、麦克风、位置、通知、下载目录或其他未预期权限提示应停止并记录，
  不要盲目点击“允许”。
- 遇到 CAPTCHA、账号登录、证书安全警告或无法判断来源的安装提示时停止；不要绕过安全警告或把它写成
  通过。

## 1. 每个平台的准备

分别准备以下四个环境：

| 编号 | 操作系统 | 浏览器 |
| --- | --- | --- |
| P-01 | Windows | Chrome Stable |
| P-02 | macOS | Chrome Stable |
| P-03 | Linux | Chrome Stable |
| P-04 | Windows | Edge Stable |

在每个环境中：

1. 从当前 checkout 执行 `./make.js package`，在扩展管理页开启开发者模式并加载当前 `dist/vimium`。
2. 核对扩展版本、扩展 ID、扩展已启用，以及权限说明中 `<all_urls>` 的披露与实际提示一致。
3. 先打开 `pages/mouse_options.html` 对应的设置页，确认六个一级分类和二级设置可以展开、折叠、搜索
   和定位；不要直接修改日常扩展配置。
4. 按下表执行功能用例，再执行无障碍用例。每个平台都要独立记录，不能把另一个平台的结果复制过来。

## 2. 功能用例

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| M-01 | 在普通静态页使用 `j/k/gg/G`、链接提示、查找、Visual、Marks 和 Vomnibar | 既有 Vimium 键盘行为仍可用，无已知回退 |
| M-02 | 在普通页按配置的触发键拖出四向后退/前进，再切换八向模式执行一个八向绑定 | 轨迹、HUD、命令和方向符合设置 |
| M-03 | 分别在菜单抑制开启和关闭时，未越过激活距离松开触发键，并测试 `Esc`/切换焦点取消 | 菜单抑制关闭时原生右键菜单保留；开启时不弹出 Chromium 菜单；两种模式均未执行未完成手势命令 |
| M-04 | 在链接、选中文本、图片上分别执行 Super Drag 的前台/后台打开、复制或搜索绑定 | 目标和绑定正确，搜索只使用用户选择的搜索引擎 |
| M-05 | 在文件上传、密码框、输入框、`contenteditable`、拖拽排序控件中拖动，并测试设置页选定的旁路修饰键（默认 `Alt`） | 不读取密码，不破坏上传、编辑和排序；选定修饰键保留原生拖拽 |
| M-06 | 进行右键/左键滚轮组合、左/右摇杆组合和未绑定按键的普通点击 | 绑定按预期触发；普通点击和普通滚动不误触 |
| M-07 | 打开标签页列表，用键盘搜索、鼠标选择、关闭和切换；选择/移除本地 PNG 指针 | 标签列表可用；指针只来自本地资源，删除后恢复默认 |
| M-08 | 在设置页修改全局开关、模块参数、绑定、语言和“使用浏览器同步设置”开关，分别切换同步/本地存储后保存并刷新页面 | 保存状态明确，刷新后值保留；同步关闭时配置只在本地保存，未修改的 Vimium 设置不被覆盖 |
| M-09 | 新增一个 Glob 站点规则和一个正则站点规则，分别停用单个模块；使用测试网址查看匹配解释 | 每个模块可独立停用；匹配顺序、规则优先级和最终状态解释准确 |
| M-10 | 导出设置；导入有效 JSON 后先取消再确认；导入非法 JSON、未知 schema 和未知字段 | 预览列出新增/修改/删除；取消不写入；非法输入被拒绝；未知字段不执行脚本 |
| M-11 | 用迁移前版本的设置/导出 fixture 导入当前版本，确认旧设置键、会话覆盖和本地指针资源 | 旧数据可读取，当前写入使用新标识；迁移失败时不静默覆盖用户数据 |
| M-12 | 在顶层页、`srcdoc`、`about:blank` 和跨域 iframe 中重复执行手势；重启或终止 Service Worker 后再执行 | 子 frame 不绕过顶层禁用；一次手势只执行一次；中断时安全取消，恢复后可重新初始化 |
| M-13 | 打开 `chrome://`、扩展管理页、内置 PDF 或其他受限页面 | 显示浏览器限制提示，操作控件不静默失效 |

## 3. 站点覆盖

使用下列站点补充 M-01 至 M-13。只需要打开公开页面即可；认证态流程必须另行取得授权并单独记录，
不能用登录页结果代替。

| 类别 | 站点/fixture | 额外检查 |
| --- | --- | --- |
| 本地 fixture | `tests/fixtures/` 中的链接、输入、滚动容器、Shadow DOM、拖放、编辑器、图片、iframe 页面 | 覆盖所有原生旁路和跨 frame 场景 |
| 普通网页 | 静态页面、长列表、无限滚动页面 | 普通滚动、页面底部和标签操作 |
| 高冲突网页 | GitHub、Google Docs、Notion、在线代码编辑器 | 检查默认站点规则和可删除性；编辑器不应被 Super Drag 接管 |
| 媒体/社区 | YouTube、Reddit | 右键、滚动和输入控件保护 |
| 搜索/代码 | StackBlitz、CodeSandbox、CodePen | 正则/Glob 规则和编辑器保护 |
| 认证入口 | Gmail、Google Docs 的登录页 | 只检查页面限制和未登录状态；不输入账号 |

## 4. 无障碍与显示

在每个平台至少执行一次，并记录实际使用的辅助技术：

- 全程只用键盘：Tab、Shift+Tab、方向键、Home、End、Enter、Space 和 Esc 可以完成导航、展开、编辑、
  保存、取消和导入预览；焦点始终可见且不会被不可见控件抢走。
- 用 VoiceOver（macOS）、Narrator 或 NVDA（Windows）、Orca（Linux）读取设置页、动作页、对话框、错误
  提示和动态保存状态；记录控件名称、角色、状态和焦点移动是否正确。
- 将系统/浏览器缩放调到 200% 及更高，启用高对比度或强制颜色，打开 `prefers-reduced-motion`；确认
  六类导航、表格、按钮、错误提示和导入预览仍可读、可操作。
- 任何未安装的屏幕阅读器或无法访问的系统能力都记录为“未执行”，不能改写为通过。
